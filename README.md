# 17-RDBMS-PROGRAM
# PL/SQL Procedure – Insert Student Record

## Question

Write a PL/SQL procedure to insert a student record into the Student table.

## Objective

To create and execute a PL/SQL procedure that accepts student details as parameters and inserts a record into the Student table.

## Student Table

The Student table contains:

- StudentID
- StudentName
- DOB
- Gender
- DepartmentID

## Expected Result

The procedure should successfully insert a student record into the Student table.
